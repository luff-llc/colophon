# Colophon 0.2

This file is a pointer. The Rust shared implementation is **Colophon 0.3**; see
[colophon-0.3.md](colophon-0.3.md) and `conformance/0.3/`.

In LUFF's Marginalia repository, "Colophon 0.2" names the Swift layout-2 step
(namespace-scoped operation paths, replaceable live playback state, a root-signed
`layout` authority entry, a verified-record cache and session readiness states).
Colophon 0.3 absorbs that design into the shared Rust core, both SDKs and the
reference relay. Do not treat Marginalia's 0.2 document as this repository's
wire protocol.

The 0.1 specification remains [colophon-0.1.md](colophon-0.1.md).
